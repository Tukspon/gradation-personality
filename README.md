# グラデーション性格診断

性格を「あなたは○○タイプ」と1つに決めつけず、**複数のタイプにどれくらい当てはまるか**を割合で示す性格診断です。
大学のゼミ研究（専門ゼミⅠ）の一環として制作しました。

## 背景

SNSではMBTIや16Personalitiesなどの性格診断が流行し、「○○タイプはこういう人」というラベリングが広がっています。
しかし、性格心理学の文献を調べると、

- **類型論（MBTIなど）**：分かりやすいが、本来連続的な性格を二者択一で分類してしまう
- **特性論（ビッグファイブなど）**：個人差を細かく表せるが、数値が並ぶだけで直感的に理解しにくい

という課題があることが分かりました。そこで、タイプ名の分かりやすさを残しつつ、性格のグラデーションも表せる表示方法として、「INTP 40%、INFP 35%」のような**複数タイプの割合表示**を考案しました。

## 特徴

結果画面では、同じ回答結果を3通りの方法で表示できます。

| 表示 | 内容 | 位置づけ |
|---|---|---|
| 割合表示 | 上位3タイプとその他の割合 | 本研究で提案する表示 |
| 1タイプ表示 | 最も当てはまる1タイプのみ | 従来の類型論的な表示 |
| 指標の%表示 | 4つの指標それぞれの割合 | 特性論的な表示 |

今後、これら3つの表示を比較し、分かりやすさと「決めつけられた感じ」の違いを調べる予定です。

## 計算方法

1. 20問（4指標×各5問）の質問に5段階で回答（1〜5 を −2〜+2 に変換）
2. 逆転項目（Q5〜Q8・Q13〜Q16）は符号を反転
3. 指標ごとに5問を合計（−10〜+10）し、割合に変換：`(合計 + 10) ÷ 20`
4. 4指標の割合を掛け合わせて、16タイプそれぞれの割合を算出（合計は100%）
5. 結果画面では、割合の高いタイプから合計70%以上になるまで表示（同率のタイプは並べて表示）

各指標の5問のうち2問は、反対側の傾向を尋ねる逆転項目です。何でも「そう思う」と答えてしまう回答の癖があっても、結果が偏りにくくなります。

例：I 70%・N 80%・T 55%・P 60% の場合
INTP = 0.70 × 0.80 × 0.55 × 0.60 ≒ 18%

## 使い方

`index.html` をブラウザで開くだけで動作します（サーバー不要・外部ライブラリなし）。
回答はブラウザ内で計算され、外部に送信されません。

### GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成
2. このフォルダのファイル（`index.html` `style.css` `script.js` `README.md`）をアップロード
3. リポジトリの **Settings → Pages** を開く
4. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます

## ファイル構成

```
index.html   画面の構成
style.css    デザイン（スマホ対応・ダークモード対応）
script.js    質問データと計算処理
```

質問を変更したい場合は、`script.js` の `QUESTIONS` を編集してください。
